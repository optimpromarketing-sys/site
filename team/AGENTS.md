# Страницы сотрудников

Каждый сотрудник должен иметь отдельную страницу с собственным URL. Не добавляйте профили сотрудников внутрь общей страницы `/team/`: это каталог со ссылками.

На каждой персональной странице `CREW_TEAM` содержит только одного сотрудника. `CREW_DIRECTORY` содержит общий список ссылок нижнего меню в одинаковом порядке на всех страницах. При добавлении сотрудника создайте отдельный HTML-файл и страницу Битрикс24, затем обновите `CREW_DIRECTORY` на всех персональных страницах и в каталоге. Старые комментарии шаблона об добавлении сотрудников в `CREW_TEAM` не применяются.

Нижнее меню — обычные ссылки. Стрелки и горизонтальный свайп на мобильном переходят на URL предыдущего/следующего сотрудника, включая циклический переход. Вертикальный скролл сохраняется. Краевые системные жесты не перехватываются.

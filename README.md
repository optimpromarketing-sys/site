# Страницы Оптим Про

HTML-блоки для конструктора Битрикс24.Сайты. Стили и JavaScript встроены в страницы.

## Структура

| Папка | Содержимое |
| --- | --- |
| [cases/](cases/) | 15 кейсов клиентов, каталог `Основная страница.html` и текстовый материал к кейсу «Пицца-Синица» |
| [apps/](apps/) | 6 приложений Оптим Про и каталог `apps-page.html` |
| [tools/](tools/) | Возможности Битрикс24: CRM, AI, задачи, коммуникации, аналитика, интеграции; обзорные страницы `capabilities.html` и `Возможности с поиском.html` |
| [articles/](articles/) | Статьи о выборе CRM и автоматизации |
| [blocks/](blocks/) | Общие блоки: шапка, подвал, секции `block-01`–`block-10`, CTA, этапы работы; резервная копия шапки |
| [templates/](templates/) | Шаблон статьи |
| [assets/images/](assets/images/) | Изображения |
| [docs/](docs/) | Справочники по страницам и Tone of Voice |

В корне остаются `index.html` — блог «Статьи и кейсы», и `services.html` — обзор услуг.

В `apps/` находятся OptimGPT, Геотрекер, Трудозатраты, Распознавание документов, Телемост и Переводчик. Страница `tools/Мобильное приложение.html` описывает встроенную возможность Битрикс24 и относится к инструментам.

## Работа со страницами

Имена файлов и содержимое перенесённых страниц сохранены. Адреса опубликованных страниц Битрикс24 в ссылках остаются прежними: папки репозитория не задают маршруты сайта в конструкторе.

Справочники: [гайд по приложениям](docs/op-crm-guide.md) и [справочник по HTML-блокам](docs/СТРАНИЦЫ_СПРАВОЧНИК.md).
Упомянутые в гайде `gen2.js`, `op-crm.css` и `op-crm.js` отсутствуют в репозитории. Для редактирования готовых HTML-файлов установка пакетов и сборка не нужны.

В подготовленной облачной среде из `/workspace/site` запустите:

```sh
python3 /workspace/site-support/serve.py
```

Этот локальный сервер обслуживает корень репозитория на порту 8000 и указывает UTF-8 для текста. Проверяйте страницы по новым путям, например `apps/apps-page.html`, `tools/CRM.html` и `cases/Основная страница.html`. Ссылки на опубликованные страницы, внешние ресурсы и интеграцию с конструктором нужно проверять отдельно в Битрикс24.

## Проверенное размещение на b24.pro

[Карта блоков и страниц](docs/deployment-map.json) содержит подтверждённые ID компонентов конструктора. [Инструкция публикации](docs/publication-guide.md) описывает проверку сохранения HTML_CODE и добавление новых блоков.

[Исправления и проверки от 7 октября 2026](docs/fixes-2026-10-07.md) сопровождаются результатами браузерных проверок и сверки опубликованных исходников. Полный исходник большого HTML-компонента старой страницы находится в [legacy/home-1022.html](legacy/home-1022.html); отдельные связанные фрагменты не заменяют этот компонент целиком.

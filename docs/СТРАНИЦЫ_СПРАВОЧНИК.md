# Справочник по созданию страниц Оптим Про (op-crm)
### Битрикс24.Сайты — HTML блоки

---

## 1. Архитектура и ограничения Битрикс24

- Каждая страница = один или несколько HTML-блоков в конструкторе Битрикс24.Сайты
- Все блоки на одной странице **разделяют общий DOM и document** — CSS и JS одного блока влияют на другие
- Блоки вставляются как `innerHTML`, поэтому `<html>`, `<head>`, `<body>` не используются
- Битрикс24 может добавлять собственные стили с `!important` — при конфликтах добавлять `!important` к нашим правилам
- `position:fixed` дочерних элементов работает относительно viewport **только если ни один предок не имеет `transform`, `filter`, `backdrop-filter`** — canvas и глобальные оверлеи лучше добавлять через `document.body.appendChild()`, а не внутрь блока

## 3. Темизация (Dark / Light)

### Логика переключения темы

| Состояние | Атрибут на `<html>` |
|---|---|
| Тёмная (дефолт) | атрибут отсутствует |
| Светлая | `data-theme="light"` |

### CSS-селекторы

```css
/* Тёмная тема (дефолт) */
html:not([data-theme="light"]) .selector { ... }

/* Светлая тема */
html[data-theme="light"] .selector { ... }
```

> ⚠️ **Никогда не использовать** `html[data-theme="dark"]` — этот атрибут не устанавливается.

### localStorage

```javascript
// Ключ хранения темы
localStorage.getItem('op-theme')  // 'light' | null

// Установить светлую
document.documentElement.setAttribute('data-theme', 'light');
localStorage.setItem('op-theme', 'light');

// Вернуть тёмную
document.documentElement.removeAttribute('data-theme');
localStorage.setItem('op-theme', '');
```

### Anti-FOUC (обязательно первым в блоке)

```html
<script>(function(){
  var t=localStorage.getItem('op-theme');
  if(t==='light') document.documentElement.setAttribute('data-theme','light');
  else document.documentElement.removeAttribute('data-theme');
})();</script>
```

### JS (частицы — добавить в конец блока)

```javascript
(function(){
  var isDark = function(){ return document.documentElement.getAttribute('data-theme') !== 'light'; };

  var pc = document.createElement('canvas');
  pc.className = 'op-particles-bg';
  pc.setAttribute('aria-hidden','true');
  document.body.appendChild(pc); // ⚠️ в body, не в .op-crm

  var ctx = pc.getContext('2d');
  var pts = []; var N = 55;

  function resize(){ pc.width = window.innerWidth; pc.height = window.innerHeight; }
  resize();
  window.addEventListener('resize', resize, {passive:true});

  for(var i=0;i<N;i++) pts.push({
    x:Math.random()*pc.width, y:Math.random()*pc.height,
    r:Math.random()*1.8+.4, vx:(Math.random()-.5)*.35, vy:(Math.random()-.5)*.35,
    a:Math.random()
  });

  function drawPts(){
    ctx.clearRect(0,0,pc.width,pc.height);
    var dark = isDark();
    pts.forEach(function(p){
      p.x+=p.vx; p.y+=p.vy;
      if(p.x<0)p.x=pc.width; if(p.x>pc.width)p.x=0;
      if(p.y<0)p.y=pc.height; if(p.y>pc.height)p.y=0;
      ctx.beginPath();
      ctx.arc(p.x,p.y,p.r,0,Math.PI*2);
      ctx.fillStyle = dark ? 'rgba(47,199,247,'+(p.a*.6)+')' : 'rgba(0,102,204,'+(p.a*.25)+')';
      ctx.fill();
    });
    // Линии между близкими точками
    for(var i=0;i<pts.length;i++){
      for(var j=i+1;j<pts.length;j++){
        var dx=pts[i].x-pts[j].x, dy=pts[i].y-pts[j].y;
        var d=Math.sqrt(dx*dx+dy*dy);
        if(d<110){
          ctx.beginPath();
          ctx.moveTo(pts[i].x,pts[i].y); ctx.lineTo(pts[j].x,pts[j].y);
          var a=(1-d/110)*(dark?.12:.05);
          ctx.strokeStyle = dark?'rgba(47,199,247,'+a+')':'rgba(0,102,204,'+a+')';
          ctx.lineWidth=.6; ctx.stroke();
        }
      }
    }
    requestAnimationFrame(drawPts);
  }
  drawPts();
})();
```

> ⚠️ **Важно:** canvas добавлять через `document.body.appendChild()`. Вставка внутрь `.op-crm` через `insertBefore` ломает раскладку в Битрикс24.

```javascript
var pg = document.createElement('div');
pg.className = 'op-page-glow';
pg.setAttribute('aria-hidden','true');
document.body.appendChild(pg);

var pgX = window.innerWidth/2, pgY = window.innerHeight/2, pgRaf = null;

function movePg(tx, ty){
  pgX += (tx-pgX)*.1; pgY += (ty-pgY)*.1;
  pg.style.transform = 'translate('+pgX+'px,'+pgY+'px) translate(-50%,-50%)';
  pgRaf = requestAnimationFrame(function(){ movePg(tx,ty); });
}
document.addEventListener('mousemove', function(e){
  if(pgRaf) cancelAnimationFrame(pgRaf);
  movePg(e.clientX, e.clientY);
}, {passive:true});
document.addEventListener('mouseleave', function(){ if(pgRaf){ cancelAnimationFrame(pgRaf); pgRaf=null; } pg.style.opacity='0'; }, {passive:true});
document.addEventListener('mouseenter', function(){ pg.style.opacity=''; }, {passive:true});
```

root.querySelectorAll('.op-feat__card,.op-extra__card').forEach(function(c){
  if(c.querySelector('.op-feat-glow')) return;
  var g = document.createElement('div'); g.className='op-feat-glow';

## 7. Scroll Reveal анимации

### CSS

```css
.op-rv { opacity:0; transform:translateY(28px); transition:opacity .7s ease, transform .7s ease; }
.op-rv.is-v { opacity:1; transform:none; }

.op-feat__card { opacity:0; transform:translateY(20px);
  transition:opacity .8s cubic-bezier(.2,.7,.2,1), transform .65s cubic-bezier(.2,.8,.2,1); }
.op-feat__card.is-v { opacity:1; transform:none; }
```

> ⚠️ **Не применять `op-rv` к hero-секции** — IntersectionObserver в Битрикс24 срабатывает с задержкой, hero остаётся невидимой и создаёт пустой экран. Для hero использовать CSS-анимации напрямую (`@keyframes opUp`).

### JS (IntersectionObserver)

```javascript
var io = new IntersectionObserver(function(ee){
  ee.forEach(function(e){
    if(e.isIntersecting){ e.target.classList.add('is-v'); io.unobserve(e.target); }
  });
}, { threshold:.08 });

root.querySelectorAll('.op-rv').forEach(function(el){ io.observe(el); });
```

## 12. Адаптив (breakpoints)

| Breakpoint | Описание |
|---|---|
| `max-width:1200px` | Ограничение контейнера |
| `max-width:960px` | Планшет: 1 колонка в карточках, горизонтальный скролл табов |
| `max-width:640px` | Мобильный: стек кнопок, уменьшение шрифтов |
| `@media(hover:none)` | Touch-устройства: отключить hover-трансформы |

### Ключевые правила для адаптива

```css
@media(max-width:960px){
  .op-feat__top { grid-template-columns:1fr; gap:24px; margin-bottom:28px; }
  .op-feat__text { order:1; }
  .op-feat__img  { order:2; }
  .op-prog { grid-template-columns:1fr; gap:0; }
  .op-tools { grid-template-columns:repeat(3,1fr); margin-top:0; padding-top:20px; } /* margin-top:0 убирает наезд */
  .op-tabs { flex-wrap:nowrap; overflow-x:auto; justify-content:flex-start; }
}

@media(max-width:640px){
  .op-tools { grid-template-columns:repeat(2,1fr); margin-top:0; }
  .op-cta-btns { flex-direction:column; align-items:center; }
}

@media(hover:none){
  .op-feat__card.is-v:hover { transform:none; }
}
```

> ⚠️ `.op-tools` в базовом CSS имеет `margin-top:-56px` для дизайнерского эффекта на десктопе. В адаптиве **обязательно** перекрывать `margin-top:0` — иначе блок наезжает на карточку выше.

## 14. Частые ошибки и их решения

| Проблема | Причина | Решение |
|---|---|---|
| Тёмная тема не работает | Используется `html[data-theme="dark"]` | Использовать `html:not([data-theme="light"])` |
| Тема не переключается обратно | localStorage хранит неверный ключ | Ключ всегда `op-theme` (с дефисом) |
| Пустой экран сверху | `op-rv` на hero + медленный IntersectionObserver | Убрать `op-rv` с hero, оставить CSS-анимацию |
| Частицы не работают | Сломана IIFE — `);` вместо `})();` | Проверить закрывающие скобки |
| Частицы создают пустое место | Canvas вставлен внутрь `.op-crm` через `insertBefore` | Вставлять через `document.body.appendChild()` |
| Свечение не видно на карточках | `mix-blend-mode:screen` + `backdrop-filter` несовместимы | Убрать `mix-blend-mode`, использовать обычный opacity |
| Текст кнопки-ссылки неверного цвета | `.op-crm a{color:var(--blue)}` перебивает | Добавить `!important` к `color` кнопки |
| Наезд описания на иконки | `margin-top:-56px` у `.op-tools` на мобильном | `margin-top:0` в media query ≤960px |
| Картинки не загружаются | `loading="lazy"` внутри `opacity:0` | Заменить на `loading="eager"` |

## 17. Блог (Блог/index.html)

### Структура

Блог — это одна HTML-страница с сеткой карточек постов. Каждый пост = отдельная страница Битрикс24.  
Добавить новый пост = добавить карточку в `#blog-grid` первой в списке.

### Обложки постов

Изображения берутся из `og:image` мета-тегов постов на b24.pro. Стандартный размер: **520×416 px**.

```css
/* Пропорции контейнера = пропорции исходника */
.blog-card__cover { aspect-ratio: 520/416; }
.blog-card__cover img { object-fit: cover; object-position: top left; }
```

Первая карточка: `loading="eager"`, остальные: `loading="lazy"`.

### Особенности canvas-частиц для блога

В отличие от стандартного варианта (секция 5), холст блога растягивается на полную **высоту документа** (не только viewport), потому что пользователь скроллит контент:

```javascript
function resizePc(){
  W = pc.width = window.innerWidth;
  H = pc.height = Math.max(document.body.scrollHeight, window.innerHeight);
}
```

Количество частиц масштабируется от площади: `Math.floor(W * H / 18000)`.

### HTML-комментарии внутри блока — критическая ошибка

⚠️ **Нельзя вкладывать `-->` внутрь HTML-комментариев** — HTML-парсер закрывает комментарий на первом `-->`:

```html
<!-- Плохо: <!-- вложенный комментарий --> → парсер закроет здесь -->
<!-- Хорошо: (вложенный текст без двойного дефиса) -->
```

Это вызывает:
- Рендер шаблонного текста как реального HTML
- Преждевременное закрытие обёрточного div
- Растяжение сетки на всю ширину (блок выходит из `.op-w`)
